夜の作品案内所 3.4 — コンテンツ強化版

このZIPには、GitHub Pagesへアップロードするサイトファイルが含まれます。
主な追加ページ：
1. guide-selection.html — 作品選びの基本
2. guide-genres.html — ジャンルの選び方
3. guide-metadata.html — 作品情報の読み方
4. guide-actress.html — 出演者から探す
5. guide-types.html — 作品タイプの違い
6. guide-checklist.html — 購入前チェックリスト
7. compare.html — 作品比較の方法
8. features.html — 編集部特集
9. glossary.html — 用語辞典
10. editorial-policy.html — 編集方針・情報確認ポリシー

ほかにトップ、検索、ジャンル、出演者、ランキング、セレクション、作品情報、サイト紹介、プライバシーポリシー、お問い合わせ、サイトマップを含みます。

重要：
- 実在作品のデータベース/APIは未連携です。検索フォームは条件表示のデモです。
- 実在しない作品・評価・レビュー・価格・出演情報を掲載していません。
- DMMアフィリエイトの審査通過や提携を示す表現はしていません。
- 公開前に contact.html の連絡手段を実際に設定してください。
- DMM/FANZAの規約、素材の利用許諾、サイト審査要件は申請前に公式情報で再確認してください。

アップロード方法：
1. ZIPを解凍する
2. 中のファイルをすべて GitHub リポジトリのルート（main）にアップロードし、同名ファイルを置き換える
3. 1〜数分待って公開サイトを再読み込みする
4. トップから新しいガイド10項目、フッター、リンクを確認する
