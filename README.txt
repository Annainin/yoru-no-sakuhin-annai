夜の作品案内所 4.1
- メインメニューを「検索・ジャンル・ランキング・出演者・ガイド・特集」の5項目に統一
- トップページからガイド・特集10項目へアクセスしやすい導線を追加
- 出演者ページを顔写真カード型のレイアウトに変更（写真・名前はすべて表示確認用サンプル）
- スマートフォンとPCに対応したレスポンシブ表示
注意：
出演者カードの人物名・写真枠はサンプルで、実在の人物情報ではありません。
実運用時は、公式に利用が認められた画像・確認済み情報へ差し替えてください。
作品サンプルも実在作品のデータではありません。検索・並び替えの実データ検証と、
公式に認められた作品データ連携は別途必要です。
GitHub PagesではZIPを展開し、中のファイルをリポジトリ直下へアップロードしてください。

【4.2 追加機能】
出演者一覧から出演者詳細ページ（actor.html）へ移動し、関連作品カードを表示。作品カードから作品詳細ページ（work-detail.html）へ移動できます。URLのidで表示内容を切り替えます。現在の人物名・作品名・プロフィール・作品属性は全て架空の動作確認用サンプルです。実在データや画像は含みません。
