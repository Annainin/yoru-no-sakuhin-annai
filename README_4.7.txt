夜の作品案内所 4.7（データ登録・公開フロー追加）

■ 今回の4.7でできること
・出演者と作品の情報を入力する管理画面を追加
・登録内容をこの端末のブラウザへ一時保存
・catalog.json として書き出し／読み込み
・catalog.json をサイトへ公開すると、出演者一覧・出演者詳細・関連出演者・作品一覧・作品詳細へ登録データを反映するための catalog.js を追加

■ 大切な前提
実在する出演者データを自動で取得する機能ではありません。DMM APIの利用権限が未確認のため、今回は手動登録の土台です。
名前・作品タイトル・タグは公式情報等で照合し、出典URLと確認日を必ず記録してください。
画像はURLを知っているだけでは利用できません。利用条件が確認できない場合は画像URLを空欄にしてください。
紹介文は自分で作成し、公式説明文の転載を避けてください。
アフィリエイトURLは正規に発行されたURLだけを登録してください。

■ アップロード方法（4.6を残したまま差分を追加）
1. ZIPを解凍し、catalog.json / catalog.js / data-manager.html をGitHubリポジトリのルートへ追加。
2. actors.html / actor.html / works.html / work-detail.html の各ファイル末尾にある
   <script src="script.js"></script>
   の直後へ、次の1行を追加：
   <script src="catalog.js"></script>
   ※4ファイルすべてに追加します。
3. style.css は変更不要です。
4. GitHubへアップロード後、管理画面を開く：
   https://annainin.github.io/yoru-no-sakuhin-annai/data-manager.html

■ 登録から公開まで
1. 管理画面で出演者を登録（ID、公式表記、出典URL、確認日、画像利用根拠メモが必要）。
2. 作品を登録（出演者IDを指定。先に出演者を登録）。
3. 「catalog.jsonを書き出す」を押す。
4. ダウンロードされた catalog.json をGitHubリポジトリのルートへアップロードして上書き。
5. 公開サイトで出演者・作品の表示を確認。

■ 一時保存について
ブラウザ内の一時保存は、同じ端末・同じブラウザでのみ利用できます。端末変更・ブラウザデータ消去前にJSONを書き出してください。
管理画面で入力しただけでは一般訪問者に公開されません。catalog.jsonをGitHubへアップロードした時点で公開されます。

■ 関連出演者の表示ロジック
登録したタグの一致数で候補を並べます。外見・顔立ちが似ているという推定はしません。タグは根拠のある情報だけ登録してください。
