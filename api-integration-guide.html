公式データ連携について

作品・出演者情報は、出典と利用条件を確認できる公式データを基準に掲載します。

データの取得元

FANZAヘルプセンターでは、アフィリエイト用の商品データはDMM Webサービスで参照できると案内されています。利用にはDMM会員登録、DMMアフィリエイト登録、API利用登録が必要です。

FANZA公式ヘルプ：API IDの取得方法

APIキーの取り扱い

このサイトはGitHub Pagesの静的サイトです。API IDや認証情報をHTML・JavaScript・JSONへ直接書くと、公開リポジトリから第三者に見えてしまいます。APIキーをブラウザ側へ埋め込む構成にはしません。

実データ連携時は、API認証情報をサーバー側の環境変数など非公開領域で管理し、必要な項目だけをサイトへ渡す方式にします。現段階ではAPIキーを入力・保存する機能はありません。

掲載前の確認

  • 作品名・出演者名・発売日などは取得元のデータと照合する
  • 画像・サンプル画像・紹介文は公式の利用条件に従う
  • 価格・配信状況・レビュー情報には確認日を持たせる
  • 確認できない情報は推測で補わず、空欄または未掲載にする
  • アフィリエイトリンクは公式APIが返すリンク等、認められた方法を使う

現在の実装状態

4.3では、作品一覧ページとデータ項目の設計見本を追加しました。画面に表示される出演者・作品は引き続き架空のサンプルです。公式APIとの接続、実在データの取得、画像の反映、成果リンクの生成はまだ行っていません。
