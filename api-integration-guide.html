API INTEGRATION

公式データ連携の設定

実在する作品情報を正確に扱うため、DMM Webサービスの公式APIを利用する準備をします。

現在の状態：4.4では接続プログラムと検索画面を用意しましたが、まだあなたのAPI認証情報・Worker URLが設定されていないため、実データ検索は有効になっていません。架空データを実在データのように表示することはしません。

1. 先に必要なもの

  • DMM会員登録
  • DMMアフィリエイトの登録（利用条件・審査状況の確認が必要）
  • DMM Webサービスの利用登録とAPI ID
  • API利用に対応したアフィリエイトID
  • Cloudflareアカウント（無料枠の範囲でWorkerを公開する想定）

公式ヘルプでは、Webサービスの利用にDMM会員登録・DMMアフィリエイト登録・API利用登録が必要と案内されています。

FANZA公式ヘルプ：商品データの取得について ／ 公式ヘルプ：API IDの取得方法

2. 認証情報はGitHubに置かない

API ID・アフィリエイトIDをHTML、JavaScript、JSON、GitHubの公開ファイルに書かないでください。4.4ではCloudflare Worker側のSecretとして保管する方式にしています。チャットにも認証情報を貼らないでね。

3. Workerを設定する

  1. Cloudflareにログインし、Workers & Pagesから新しいWorkerを作成。
  2. ZIP内の worker.js の内容をWorkerのコードとして貼り付けて保存・デプロイ。
  3. WorkerのSettings → Variables and Secretsで、Secretとして DMM_API_ID と DMM_AFFILIATE_ID を登録。
  4. 通常の環境変数として ALLOWED_ORIGIN に公開サイトのオリジン https://annainin.github.io を設定。
  5. WorkerのURLを控える。URLは公開してもよいが、API認証情報は公開しない。

Cloudflareの画面表示は変更されることがあります。設定画面の名称が異なる場合は、Cloudflare公式ドキュメントを確認してください。

Cloudflare Workers公式ドキュメント

4. サイト側にWorker URLを設定

api-config.js の空欄に、デプロイしたWorkerのURLだけを設定します。

window.YORU_API_BASE_URL = 'https://あなたのWorker URL';

このファイルにAPI IDやアフィリエイトIDは絶対に書かないでください。変更後、GitHubへアップロードします。

5. 動作確認

  1. 公式データ検索ページを開く。
  2. 作品名やキーワードを入力して検索。
  3. APIから返った作品タイトル・画像・出演者・ジャンル・公式リンクを確認。
  4. エラーの場合はWorkerのSecret名、API利用登録、API用アフィリエイトID、Workerの許可オリジンを確認。

6. 公開前の確認

  • DMM Webサービスの利用規約・表示ルール・クレジット要件を必ず確認。
  • 取得した画像や商品情報の加工・保存・再配布は、許可範囲を確認してから行う。
  • 価格・配信状況は変更されるため、最新情報は公式ページで確認できる導線を設ける。
  • APIで取得した商品データを他社アフィリエイト用途に流用しない。
  • API連携だけで審査通過が保証されるわけではない。独自の紹介・選び方・編集方針も充実させる。
