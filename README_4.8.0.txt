夜の作品案内所 4.8.0 — サイト全体版

【このZIPについて】
このZIPは、GitHub Pagesのリポジトリのルートへ展開して使用するサイト全体版です。ZIPファイル自体をGitHubへアップロードするのではなく、解凍した中のファイルをアップロードしてください。

【主な内容】
・作品一覧：作品名／出演者／品番の検索、登録済みジャンルによる絞り込み
・出演者一覧／出演者詳細：10名の出演者と関連作品
・作品詳細：メーカー、レーベル、品番、発売日、収録時間、出典、確認状況、確認メモ
・ジャンルページ：実際のカタログに登録されているジャンルだけを表示
・ピックアップ：人気ランキングを捏造せず、メーカー公式商品ページで確認できた作品を紹介
・編集部ガイド：既存10記事＋新規2記事（合計12記事）
・18歳以上の確認画面
・サイトについて／編集方針／プライバシー／お問い合わせ／サイトマップ
・ローカル専用データ管理画面（data-manager.html）

【カタログ】
・出演者：10名
・作品レコード：22件
・作品画像：利用条件を確認できていないため未掲載（プレースホルダー表示）
・アフィリエイトURL：未登録。正式に発行されたURLのみ後から追加してください。
・DMM Web Services API：未使用
・作品ごとに出典と確認状況を表示します。22件すべてがメーカー公式個別ページで確認済みという意味ではありません。

【アップロード手順】
1. ZIPを解凍します。
2. 解凍したフォルダ内のファイルをすべて選択します。
3. GitHubリポジトリ Annainin/yoru-no-sakuhin-annai のルートへアップロードします。
4. 同名ファイルは置き換え、新規ファイルも追加します。
5. GitHub Pagesの反映後、トップ／検索／ジャンル／作品一覧／出演者／作品詳細／ガイド／年齢確認をスマホで確認します。

【データ管理画面】
data-manager.html は公開サイトからリンクしていません。ブラウザ内だけで動作し、サーバーへ直接書き込みません。使う場合は、最初に公開中の catalog.json を読み込んでから編集してください。書き出した catalog.json をアップロードするまで公開内容は変わりません。

【重要：再審査前に残っている作業】
1. contact.html に、運営者が実際に受信・返信できるメールアドレスまたは問い合わせフォームを設定する。
2. 作品データのうち、第三者一覧情報のみ／個別商品ページ未照合のものを追加確認する。
3. 同じ作品タイトルが別出演者一覧に重複している候補が2レコードあります。作品・出演者の紐づけを確認する。
4. 画像を掲載する場合は、利用条件が確認できた素材だけを使う。
5. アフィリエイト審査通過後、正規発行されたアフィリエイトURLを設定し、広告表示を明記する。
6. 公開後に全リンク・全ページ・スマホ表示を最終確認する。

この版はサイト全体の機能・コンテンツを統合した公開前ビルドです。連絡先設定や一部作品情報の照合が残っているため、現時点でDMMアフィリエイト再申請を行う段階ではありません。
